Common questions

My invitation expired, or I typed the wrong username

Invitations expire after 7 days. A nightly job re-invites expired invitations, so a fresh one arrives within about a day: accept it. If you mistyped the username at checkout, or nothing arrives, reply to your purchase email and support will sort it out.

What do I need to run it?

Claude Code v2.1.207 or newer and Node.js, 20 or newer recommended (it runs on Node 18 with an upgrade notice). You also need a TeeInBlue account and an API token created in the TeeInBlue portal.

How does installation work?

Accept the GitHub invitation, then run the two install commands under How it works. Finish with /plugin configure to set your license key and TeeInBlue API token, and run /teeinclaw:doctor to verify the connection.

Which machines does the license cover?

One user on up to three activated machines. The license validates against the Lemon Squeezy license API.

What if something breaks?
